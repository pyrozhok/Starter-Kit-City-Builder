## Lessons → skill changes

- The false finding #2 came from aiming the check at the subject only. The rule was "each commit's diff matches its message", and the body was part of the message. Step 4 now says subject **and** body (`git log -1 --format=%B`), and that a change the body describes is covered (`7e4f65b`). This is the same lesson as 002: a check counts only when it covers what the finding claims.
- The tuple regression came from relaying a sub-agent's smell without checking it against 001 and the code comment. Step 5 now says decisions explained in a code comment, `docs/adr/` or a graded eval stay settled, in any list, judgement calls included, unless there is new evidence (`7e4f65b`).
- Wins: reproduction beat reading again. The orphan hypothesis looked plausible from reading `logger.gd`, and the probe settled it. The compile check caught a GDScript fix that would not have compiled.
- Python fixes went unchecked (1/4) because step 5's "every proposed fix is checked" only said how to check GDScript. The MCP server keeps running the Python it loaded, so `godot.*` can't check a `godot_mcp.py` fix until the server is reconnected. Step 5 now covers Python in `tools/mcp`: run its pytest suite, and until one exists, a stub probe on old and new code (`c29d596`). Next task: that pytest suite.
