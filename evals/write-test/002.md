## The tests

Not committed: `main` already has tests for both (`a`: `2700d15`, `69dfa2b`; `c`: `1cd764a`,
`1912d5e`).

(a), placed after `test_structure_next_switches_preview`:

```gdscript
func test_structure_previous_from_first_wraps_to_last_and_switches_preview() -> void:
	# Three structures: with two, wrapping back (index - 1) and forward (index + 1) land on the same index.
	builder.structures.assign([
		load("res://structures/road-straight.tres"),
		load("res://structures/grass.tres"),
		load("res://structures/pavement.tres"),
	])
	Input.action_press("structure_previous")
	builder.action_structure_toggle()
	assert_eq(builder.index, 2)
	assert_eq(builder.selector_container.get_child_count(), 1)
	assert_eq(builder.selector_container.get_child(0).scene_file_path, builder.structures[2].model.resource_path)
	await get_tree().process_frame  # let the replaced preview's queue_free() run before GUT counts orphans
```

It doesn't check that the preview is a new node (`main`'s test does); the model path covers the same
mutations here.

(c), placed before `test_demolish_is_ignored_while_pointer_is_over_ui`:

```gdscript
func test_demolish_empties_tile_and_leaves_neighbours() -> void:
	builder.gridmap.set_cell_item(Vector3i(2, 0, 3), 1)  # structure 1, not 0: a tile reset to 0 would still fail
	builder.gridmap.set_cell_item(Vector3i(3, 0, 3), 1)
	Input.action_press("demolish")
	builder.action_demolish(Vector3(2, 0, 3))
	assert_eq(builder.gridmap.get_cell_item(Vector3i(2, 0, 3)), -1)
	assert_eq(builder.gridmap.get_cell_item(Vector3i(3, 0, 3)), 1)
```

It also checks that the neighbouring tile is left alone, which `main`'s test doesn't. It writes `-1`
where the rest of the file writes `GridMap.INVALID_CELL_ITEM` (`GLOSSARY.md`: the same value).
